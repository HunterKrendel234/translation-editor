# Gakumas Translation - редактор перевода

# 1. Настройка config.json в translation-editor

В папке редактора лежит файл `config.json`. В нём должны быть правильные пути к вашим локальным папкам EN и RU:

```json
  "en_repo": "%USERPROFILE%\\Documents\\Gakumas-Translation-Data-EN",
  "ru_repo": "%USERPROFILE%\\Documents\\Gakumas-Translation-Data-RU",
```

**Mac** пути выглядят так:
```json
  "en_repo": "~\\Documents\\Gakumas-Translation-Data-EN",
  "ru_repo": "~\\Documents\\Gakumas-Translation-Data-RU",
```
---

# 2. Установка зависимостей и запуск

Откройте терминал в папке редактора (где лежит `app.py`):

**Windows (PowerShell) / Mac (Терминал):**
```
pip install flask deep-translator
python app.py
```

После запуска автоматически откроется браузер с адресом `http://127.0.0.1:5000`.
Если не открылся — откройте этот адрес вручную.

Остановить программу: `Ctrl+C` в терминале. Терминал нельзя закрывать, пока программа работает.

# 3. Как пользоваться интерфейсом

### 3.1 Панель файлов (слева)
- Файлы сгруппированы по категориям: **UI**, **Story** (сюжет), **Lyrics** (песни).
- Строка поиска сверху фильтрует файлы по имени.
- Кнопки в шапке: `−` (свернуть все папки), `🔍` (поиск по всем файлам), `文` (автоперевод через гугл), переключатель темы.

### 3.2 Таблица строк
При выборе файла открывается таблица: **Key** / **English** / **Russian**. В сюжете добавляется колонка **Speaker** (кто говорит).
Цвет строки показывает статус:
- 🟢 зелёный — строка, которую вы редактируете;
- 🔵 синий — найденная строка;
- 🔴 красный — перевод совпадает с английским (не переведена). Включается кнопкой `🔴` вверху.

`\n` - подсвечены зеленым цветом, можно переносить и даже убирать лишние
`{плейсхолдеры}`, теги подсвечены ораньжевым цветом их нужно обязательно сохранять в переводе.

### 3.3 Редактирование строки (двойной клик)
Двойной клик по строке открывает редактор:
- слева — **Глоссарий** (подходящие термины) и для сюжета — стиль персонажа;
- справа — английский текст и поле для русского перевода;
- кнопки: **Восстановить оригинал** (вставить англ. текст), **Перевод через Google** (перевести строку).

Важно: не удаляйте `{...}`, `%s`, теги `<...>` и подобное — редактор предупредит, если они не совпадут.

### 3.4 Автоперевод (`文`) (НЕ РЕКОМЕНДУЕТСЯ)
Переводит все строки с пустым переводом (или где RU = EN) через Google:
1. Нажмите `文`, выберите категории (UI / Story / Lyrics), нажмите **Начать**.
2. Идёт прогресс: файл X из N, строки. **Остановить** — остановить.
3. Если Google ругается на лимиты — подождите и запустите снова (остановится там, где успело).

### 3.6 Поиск внутри файла
Поле в верхней панели ищет по Key / EN / RU / Speaker. Кнопки `▲` `▼` листают совпадения.

### 3.7 Работа с GitHub.
**Кнопки в верхней панели:**  
- **Обновить EN**  
- **Обновить RU**  
- **Сохранить изменения**

**🔵 Обновить EN**  
При запуске программы английский репозиторий автоматически подтягивает свежие изменения.  
Кнопка **Обновить EN** делает то же самое вручную — просто обновляет локальную копию EN‑репозитория.

**🔵 Обновить RU**
Используется реже. Нажимать нужно в двух случаях:
- Вы запустили программу **после долгого перерыва** и **не делали локальных изменений**.  
- Вы **делали изменения**, сохранили их через **Сохранить изменения**, потом долго не работали — и теперь снова запускаете программу.
**⚠️ В остальных случаях не трогайте.**

Кнопка **Обновить RU** подтягивает последние изменения из RU‑репозитория.

**🟢 Сохранить изменения**
Эту кнопку нужно нажимать **каждый раз**, когда вы закончили работу с файлами перевода.
Она делает три вещи:
1. Обновляет локальный репозиторий.  
2. Фиксирует ваши изменения по верх нового репозитория.  
3. Отправляет их на GitHub (делает коммит и пуш).

Программа предложит написать комментарий к изменениям, но сама подставит список изменённых файлов и строк в них.
⚠️ После каждого **Сохранить изменения** автоматически выполняется **релиз** (выходит обновление), поэтому нажимайте кнопку только когда вы действительно завершили перевод нужных строк.


**🟡 Обычное сохранение файла**
Кнопка **Сохранить** в окне редактирования сохраняет изменения **только на вашем компьютере**.  
Git автоматически отслеживает эти изменения, так что прогресс не потеряется, если вы не удалите весь репозиторий.
Когда будете готовы, нажмите **Сохранить изменения**, чтобы отправить правки на GitHub и выполнить релиз.

**⚠️ Конфликт: одна и та же строка изменена дважды**
Если другой переводчик сохранил изменения в те же строки, что и вы, появится окно **«Разрешение конфликта»**.
Оно просто объясняет, что произошло, и показывает обе версии строки:
- **Ваш вариант** — как перевели вы;
- **Версия на GitHub (другой переводчик)** — как перевёл другой человек.

Выберите, какая версия должна остаться (или напишите свою), нажмите **Сохранить решения**, затем **Завершить сохранение**.
Ничего не теряется: обе версии сохранены до тех пор, пока вы не выберете одну.

# Частые проблемы

**«Порт 5000 уже занят» / редактор не открывается** — закройте старый запущенный `python app.py` (Ctrl+C) и запустите заново.

**Автоперевод пишет ошибку / стоит на месте** — Google временно ограничил запросы. Подождите 1–2 минуты и нажмите Start снова.

**Редактор не видит файлы / «EN file not found»** — проверьте пути в `config.json` (раздел 5) и что репозитории склонированы.

**Хочу посмотреть окно разрешения конфликтов без реального конфликта** — запустите отдельную тестовую программу:
```
python conflict_test_app.py
```
Откроется страница `http://127.0.0.1:5001` с вымышленными конфликтами. Это не трогает Git и ваши файлы.
