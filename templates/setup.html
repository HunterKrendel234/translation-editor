Проверка Git

Git нужен для работы с репозиториями переводов.

Git не найден. Установите его:

Windows

  1. Скачайте установщик Git for Windows/x64 Setup: git-scm.com/download/win
  2. Запустите .exe и нажимайте Next на каждом шаге

macOS

Откройте Терминал и выполните:

brew install git

Репозитории переводов

Нужно скачать два репозитория с данными переводов.

Выберите папку, куда будут скачаны репозитории (по умолчанию ~/Documents):

EN - Исходные данные
✓
RU - Данные перевода
✓

Привязка GitHub (SSH)

Для отправки изменений нужно настроить SSH-ключ и привязать его к вашему аккаунту GitHub.

Теперь добавьте ключ на GitHub:

  1. Откройте github.com/settings/keys
  2. Нажмите New SSH key
  3. Title: любое имя (например: my pc)
  4. Key type: Authentication Key
  5. В поле Key вставьте скопированный ключ
  6. Нажмите Add SSH key

Настройка завершена!

Всё готово. Теперь можно начинать работу с редактором переводов.
